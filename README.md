# Tourism Analytics Dashboard

An AI-powered tourism analytics dashboard with LSTM-based predictions and interactive visualizations.

## Features

- Multi-country tourism data analysis
- LSTM neural network forecasting
- Interactive visualizations with Plotly
- Seasonal pattern analysis
- Dark mode support

## Demo

Visit the live dashboard at: [lstmapp.streamlit.app](https://lstmapp.streamlit.app/)

## Setup

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`

## Data

The dashboard uses tourism data from 2010-2025 with monthly visitor counts by country.

## Model

The forecasting engine uses a Long Short-Term Memory (LSTM) neural network trained on historical tourism data.
